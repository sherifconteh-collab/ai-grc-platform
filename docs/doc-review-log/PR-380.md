# Documentation review — PR #380

Performed live by the Claude Code session that opened the PR. Scope: the
top-level docs that describe the desktop app (`README.md`, `QUICKSTART.md`,
`PROJECT_STATUS.md`, `docs/*.md`) checked against this PR's launcher rewrite,
the four backend/frontend fixes and the CI changes.

## Fixed in this PR

- **First launch and sign-in** (`README.md` "Download the Desktop App",
  `QUICKSTART.md` Option 1): both said the app opens straight into sign-in or
  registration. It now shows a startup window and, on first launch, the
  generated administrator credentials; both docs describe that, plus
  **Help → Show First-Run Sign-In Details**.
- **Troubleshooting** (`README.md`): new section with the data and log
  folder paths (`controlweave-desktop`, verified from the packaged
  `package.json`), the port 3001 requirement, and crash recovery. None of
  this was documented.
- **Build from source** (`README.md`): adds `npm run smoke` before building
  an installer.
- **Disk space** (`README.md` system requirements): said ~500 MB. A packaged
  build measures 1.2 GB unpacked (about 1.1 GB with the production-only
  backend dependencies this PR switches to), so it now says ~1.5 GB including
  data. This was stale before this PR.
- **Launcher internals**: new `electron/README.md` (module layout, ports,
  tests, `--smoke-test`, and the install-then-boot scripts for each
  platform).
- **Release verification** (`README.md`): now says each installer (`.exe`,
  `.dmg`, AppImage) is installed the way a user installs it before being
  booted in CI, matching `scripts/smoke-installed.*` in both workflows.

## Verified already correct — no change needed

- `PROJECT_STATUS.md` "Electron desktop app with embedded PostgreSQL (no
  setup required)" and "Auto-update via electron-updater": still true.
- `README.md` architecture diagram "Desktop App (Electron, bundled
  PostgreSQL)" and "PostgreSQL 17+": the bundled server is PostgreSQL 17.
- `README.md` Windows SmartScreen note: still accurate; signing is unchanged.
- `QUICKSTART.md` download table: artifact names unchanged.

## Out of scope — noted, not changed

- `README.md` line 27 says desktop builds include "Redis-backed rate limiting
  and caching, automated database backups". The desktop app runs without
  Redis (the backend logs `server.startup.redis_not_configured` and uses
  in-memory limits), and backups need `pg_dump`, which the app does not
  bundle. Pre-existing; worth correcting in a docs follow-up.
- `README.md` and `QUICKSTART.md` development prerequisites say Node.js 20+
  and PostgreSQL 14+; the backend requires Node 24 and the project targets
  PostgreSQL 17. Pre-existing, unrelated to the desktop app.
